## Problem

1. **U-18 not met.** Engine keypad questions used MathQuest's `engine-keys` keypad, which showed "digits plus the symbols the answer needs". U-18 requires one pad with the full key set on every question, keys that never depend on the answer, built in the Engine. Number and skill-fraction questions used two further MathQuest keypads.
2. **U-14 version drift.** MathQuest recorded Engine 0.34.0-rc.3; Math Arcade is on 0.63.0 going to 0.65.0. Engine 0.37.0+ keeps questions that need more than one answer out of games; MathQuest still delivered them.

## Changes

1. **Engine bundle 0.65.0** (`src/vendor/`, `public/engine-catalog.js`): 4,147 catalog entries (was 1,763), including Intermediate 4, Algebra 1/2 and Algebra 1 ports.
2. **Game exclusion:** `engineIdsFor` returns only ids the Engine allows in games. A saved setup or room naming an excluded id skips it. The retired module **number.scientific-notation** mapped only to two excluded items (MCADA-51.1, MCADA-57.2: "Enter coefficient; exponent"). It now runs on the same lessons' single-answer siblings, **MCADA-51.2** and **MCADA-57.3** (scientific notation → standard form). *Owner to confirm (see Open decisions).*
3. **Answer types:** every Engine keypad question is `engine-pad`; choice questions stay `choice` (answer buttons); typed-text questions stay `engine-text` (text box; U-18 boundary). The MathQuest `number`, `fraction` and `engine-keys` keypads are no longer used for Engine questions. Fractions are typed with a slash (`3/4`), mixed numbers with a space.
4. **Universal pad in the browser:** `scripts/sync-math-engine.mjs` now also writes `public/engine/answer-pad.js`, an ES-module wrapper around MATH-ENGINE `src/answer-pad.js` (unedited; commit recorded). MathQuest only places and colours it.
   - **Gates** (`public/app.js`): the pad types into the answer display; the draft and the open tab survive the 2.5-second poll re-render; a new question opens on 123. Physical keyboard goes to the pad; MathQuest's own gate key handler stands aside while the pad is on screen, so nothing is typed or submitted twice. Enter submits.
   - **Journey optional questions** (`public/games/journey/`): the same pad under a read-only answer box. The pad is loaded on demand; if it cannot load, the box becomes a normal typed box so the question can still be answered.
5. **Unchanged answer checking:** `Engine.evaluate` reads pad text (− ÷ √ ×, AM/PM) itself.
6. **Rooms survive the upgrade (U-06):** the Worker's list of supported room versions lacked 0.13.0, 0.14.0 and 0.14.1, so a room open during a Worker update was refused ("This room belongs to an older release"). They are added.
7. **Version (U-01):** frontend and Worker 0.15.0 (`package.json`, Worker `VERSION`, `BRAND`, page title, cache keys, release validation).

## Preserved (U-06)

Session structure, gates and allocation, teams/Event Lead, resources/market, equipment, every cartridge's gameplay and story, Foundation/Challenge links (D4), teacher picker and Preview / Next variant, reporting fields (engine id and version), teacher-authored question imports and their existing input controls (not code-generated mathematics; see Open decisions), the crew-message letter keypad (outside U-18), U-10 input code, hosting and privacy. Rooms already running keep working: items they issued under 0.34 still render with their original controls.

## Deployment order

Merging to `main` redeploys the frontend on Render automatically. The Worker is deployed separately (`Deploy_Backend_Windows.bat`). Deploy the **Worker right after the merge**: the new frontend still draws the old controls for the old Worker's questions, but the old frontend cannot draw `engine-pad`.

## Open decisions

- **Scientific-notation replacement** (change 2): accept MCADA-51.2/57.3, or choose other items.
- **Teacher-authored imports** still use MathQuest's structured inputs (fraction boxes, ratio, scientific). U-18 says every on-screen math pad is the Engine pad. Moving imports to the pad changes how their answers are parsed, so it is left for a separate decision rather than changed silently.
- **Engine host map:** the scientific-notation replacement could move into MATH-ENGINE `docs/host-maps/mathquest-modules-v0.1.json` so the Engine owns it.
