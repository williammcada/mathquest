# WebP game art — MathQuest part of the game-loading plan

**Status:** Owner-approved 16 October 2026 (Asia/Shanghai). Implementation on branch `implement/webp-art` from `main` `5a5d7c6`.
**Canonical specification:** Math-Arcade `docs/change-specs/game-loading-2026-10-16.md` (Phase 1). This file records the MathQuest scope.

## Why

Journey to the West loaded about 45 MB of PNG art per launch (20 sprite atlases at 1536×1024), slow on school Wi-Fi in both MathQuest and Math Arcade, which syncs these files. Nightfall loaded 7.5 MB.

## Owner decisions

1. WebP quality 90 at the same pixel size, released only after the owner approves side-by-side screenshots; lossless is the fallback for any image that looks different.
2. PNG originals move to `art-source/` in this repository, outside the published `public/` folder.

## Change

- Journey: 20 sprite/item atlases and `cast-concept` served as WebP quality 90, same size, alpha unchanged (stored losslessly). Code references updated (`hero-art.js`, `enemy-art.js`, `frame-repairs.js`, `renderer.js`, the Journey briefing image in `src/cartridges/journey/server.js`, the cartridge cover in `public/cartridges.js`). Environment WebP files were already in use and are unchanged; their PNG originals also move to `art-source/`.
- Nightfall / False Haven: shared NF-ART-01 sheets served as 512 px WebP (the size the renderer already decoded them to); city pixel-art atlases served as lossless WebP. `sprites.js` and `renderer.js` updated.
- `scripts/art/convert-webp.py` rebuilds every WebP from `art-source/` and checks size, alpha and lossless pixels. Frame-bound and city-media scripts read and write the originals in `art-source/`.
- `scripts/build-journey-practice.mjs` embeds the WebP files (this also embeds the environment backgrounds, which the previous `.png`-only filter left out).
- `scripts/validate-release.mjs` checks the 1024 px PNG originals and their WebP builds, and that no PNG is left in `public/assets/journey/`.

## Not changed

Art content, frames, animation data, gameplay, Worker, audio. Historical review bundles in `public/reviews/` are frozen builds and keep their old references.

## Release requirement

Released as frontend 0.14.2 (Worker unchanged at 0.14.1; `BRAND.engineVersion` stays 0.14.1). Old cached scripts still name `.png` files that are no longer published, so the version bump is what makes browsers fetch the new scripts.
