## Owner requirement

Wherever mathematics is generated by code it comes from the Math Engine, from Kindergarten to Algebra 2. MathQuest and Math Arcade stay synchronized on the same engine.

## Changes

- **Questions:** every code-generated question and every check of a code-generated answer goes through the vendored engine bundle (`src/vendor/math-engine-practice.js`, refreshed by `scripts/sync-math-engine.mjs`). `src/engine-questions.js` adapts engine items to MathQuest records; `src/answer-check.js` is the single check used by gates and Journey.
- **Retired generators (D3):** the 25 preset modules in `src/math.js` and `src/math-v06.js` are removed. Each maps to engine items (`src/vendor/mathquest-module-map.js`); five constructs with no prior engine equivalent were added to the engine first. Rooms and saved setups that name an old module run on its mapped engine items. Teacher-authored imports keep MathQuest's import parser (not code-generated).
- **Difficulty (D4):** the Beginner/Intermediate/Advanced band is retired. A student's Foundation/Challenge setting uses the engine's reviewed easier/harder related item, or the selected item when no link exists. Recorded as `assignedDifficulty`.
- **Teacher setup (D5):** a Math Engine picker replaces the 25 module cards: level filter (MathQuest sets, Grades K–7, six courses Intermediate 4 → Algebra 2, extras), search, selected list with question counts, and Preview (`/api/engine-preview`, no state change).
- **Student input:** existing fraction/number/choice controls where they fit; new `engine-keys` keypad (digits plus the symbols the answer needs, e.g. R, :, ;, AM/PM, <, x) and `engine-text` typed answers. Keyboard: `a`/`p` select AM/PM. Journey optional questions support the same types and show engine diagrams.
- **Fractions (MATH-FRAC-01):** engine `evaluate()` gives the simplest-form message wherever an item requires simplest form; malformed entries are refused without counting an attempt.
- **Version (U-01):** 0.10.0 in package, Worker, brand, page titles (static and rendered), cache keys, connection test.

## Preserved

Session structure, gates and allocation, teams/Event Lead, resources/market, equipment, cartridges' gameplay and stories, reporting fields (plus `source: math-engine`, engine id and version), privacy and hosting architecture, supported older room versions (0.9.2–0.9.7), U-10 input code (unchanged).

## Not in scope

Math Arcade migration (separate release), Mega Man, Math Civ, deployment.
