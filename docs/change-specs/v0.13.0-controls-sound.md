# MathQuest v0.13.0 — Shared D-pads and iPad sound (change specification)

**Status:** Draft for owner approval (requested 2026-10-15). Nothing implemented.
**Baseline:** `main` `30ef827` (MathQuest 0.12.0).
**Handbook:** `williammcada/mcada-project-handbook` `6e1f5a4` (v0.1.11): U-01, U-05, U-06, U-07, U-10, U-13, U-17; S-03, S-04.
**Origin:** Math Arcade v0.8 (PR #9 merged, PR #10 open) fixed D-pads and iPad sound in Arcade-owned files. The sync runs MathQuest → Arcade only, so MathQuest still has the old controls and sound. Owner, 2026-10-15: move the fixes into MathQuest's shared engine so both products share one copy.

## 1. Goal

One implementation, owned by MathQuest, used by MathQuest's games and pulled into Math Arcade by the normal sync:

- `public/engine/pad.js` — the U-17 pads (Mega Man **cross**; **8-direction** pad with corner arrows, no empty cells), on the existing `held-input.js` (U-10).
- `public/engine/audio-unlock.js` — the iPad sound fix.

The Arcade's own copies are then deleted in a follow-up Arcade change (§5).

## 3. Sound on iPads

Source: Math Arcade `public/audio-unlock.js` (v0.8.1).

- Loaded first on the student page and on every practice / DEV / standalone page: playback audio session (the side switch no longer mutes Web Audio), every tap resumes suspended audio, a game's `resume()` never stalls, sound-off memory lasts one page load (music on by default).
- Fix in the shared `game-audio.js`: Sound button can no longer throw (`master` undefined) or need two taps.
- Journey: add a master volume with a limiter inside `games/journey/audio.js` (replaces the Arcade's wrapper boost).
- Vault 7 (`stealth.js`), Ironbreak, Blackline, Kingsgate, Blackout audio: covered by the shared unlock; their Sound buttons checked for the same first-tap-off problem.
