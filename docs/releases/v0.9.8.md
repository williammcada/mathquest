# MathQuest v0.9.8 — release notes

**A WILLIAM MCADA PRODUCT** · 13 October 2026

Release of the verified action-difficulty checkpoint (`6940ce6`, verification in `action-difficulty-2026-10-13.md`). This release step only changes version numbers and documentation; no gameplay was added.

## What changed

- **Coastal Escape flight v0.4.0:** 150-second approach with mixed multi-enemy patterns, 150-second boss section, triple-strength battleships, faster enemy fire, supplies that stay until they leave the screen, sprite-drawn boss finale.
- **Ironbreak v0.2.1:** level twice as long (second loop and MID2 checkpoint), 86 robots, faster boss with a mortar barrage; swimming no longer pauses the run.
- **Blackline v0.3.2:** road obstacles, aerial shell strikes that can be steered, boosted or braked away from, boost-required gaps.
- **DEV playtest mode (handbook U-13)** for all three: every power-up and starting point selectable, no questions, no records.
- Platform and session engine **0.9.8**. Rooms created on 0.9.2–0.9.7 remain supported.

## Deployment order

The website and the session engine must change together, because the engine checks the new game versions.

1. Merge the release into `main`. GitHub Pages publishes the website within a few minutes.
2. Immediately run `Deploy_Backend_Windows.bat` on the Windows computer (it tests, then updates the existing `mathquest-prototype` Cloudflare Worker).
3. Open `https://vault7mathquest.netlify.app/api/health` and confirm `"version":"0.9.8"`.
4. Math Arcade picks up the new games through its hourly upstream sync; its own verification must pass, and its Cloudflare deployment is a separate manual step.

## Known limits

Physical iPhone/iPad checks and school-network tests are not yet run. Ironbreak keeps the 5-minute window for a level twice as long. Blackline interceptors stay off-screen behind the player (accepted by the owner for now).
