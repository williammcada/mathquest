# MathQuest v0.11.0 — release notes

**A WILLIAM MCADA PRODUCT** · 13 October 2026

Adds the **Kingsgate** cartridge (cartridge `kingsgate-cartridge-0.1.0`, game `kingsgate-defense-0.1.0`). Approved specification: `williammcada/kingsgate` `docs/change-specs/kingsgate-v0.1.md`. MathQuest notes: `docs/change-specs/kingsgate-v0.1.md`. Includes everything in v0.10.0.

## What changed

- **Kingsgate**, a tower defense cartridge: orc warbands attack the walled city of Kingsgate in twelve waves, ending with a Siege Ram. Students build and upgrade Archer Towers, Ballistae, Mage Towers and Catapults on ten build spots.
- Story gates Ring the Bells, Stone and Mortar and The Granary Count, with optional inserts Arrows for the Wall and The Bridge Timbers. Crew vote: evacuate the lower town or hold the river bridge. Final vote: ride out, collapse the pass, or fortify the gate.
- Equipment: Archer and Ballista always available; Mage Circle, Siege Yard, War Chest and Reinforced Gate earned through preparation.
- One five-minute individual defense per student; the result is reported separately from mathematics. A guided defense is available.
- Owner DEV playtest: Developer tools → Kingsgate v0.1.0.
- The game host accepts taps on the battlefield for games that use them; existing games are unchanged.
- Platform and session engine **0.11.0**. Rooms created on earlier versions remain supported.

## Deployment order

The website and the session engine must change together: the website refuses to create sessions unless the server reports the same version.

1. Merge the MathQuest pull request for `implement/kingsgate-v0.1` into `main`. GitHub Pages and Netlify publish the website within a few minutes.
2. Immediately run `Deploy_Backend_Windows.bat` on the Windows computer (it tests, then updates the existing `mathquest-prototype` Cloudflare Worker).
3. Open `https://vault7mathquest.netlify.app/api/health` and confirm `"version":"0.11.0"`.
4. Start a test session, choose Kingsgate, and play through one gate.

## Known limits

Physical iPhone/iPad checks and school-network tests are not yet run. The Math Arcade entry is a separate Math-Arcade change after this release.
