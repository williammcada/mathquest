# MathQuest v0.12.0 — release notes

**A WILLIAM MCADA PRODUCT** · 14 October 2026 · Stage: verified checkpoint on `implement/mathquest-v0.12.0` (code verified at `2f04b8a`; not deployed)

## Why this release exists

The owner found that finished game work had not reached MathQuest. An audit of every branch against `main` (14 October 2026) found two verified branches that were never merged:

| Branch | Content | Previous state |
| --- | --- | --- |
| `implement/nightfall-art-v1.0.0` | Nightfall Art Direction v1.0.0 (sprite-drawn world objects, painted roofs/decals/furniture, reachability guard; First Response, Last Bus Out, False Haven v0.4.0) | Owner desktop playtest passed 13 Oct; never merged |
| `implement/blackout-protocol-v0.2.0` (draft PR #11) | Blackout Protocol cartridge v0.2.1 | Verified candidate; never merged |

The Coastal Escape v0.4.0, Ironbreak v0.2.1 and Blackline v0.3.2 difficulty work, Math Engine questions (0.10.0) and Kingsgate (0.11.0) were already on `main` and stay unchanged. (Math Arcade lagging behind MathQuest is a separate cause: its Worker is not redeployed after its hourly sync. That is fixed in Math Arcade, not here.)

## What changed

- **Nightfall Art Direction v1.0.0** merged. See `docs/releases/nightfall-art-v1.0.0.md` and the NF-ART-01 standard in the project brief.
- **Blackout Protocol v0.2.1** merged as a classroom cartridge alongside Kingsgate. See `docs/releases/blackout-protocol-v0.2.1.md`. DEV: Developer tools → Blackout Protocol v0.2.1.
- Shared game host now supports both tap styles: Kingsgate's battlefield taps and Blackout's letterboxed taps with latched presses.
- Platform and session engine **0.12.0**. Every platform cache tag advanced to `?v=0.12.0` so browsers fetch the new Nightfall and Blackout files. Connection test page 1.2.0. Rooms created on 0.9.2, 0.9.4–0.9.8, 0.10.x and 0.11.0 remain supported.
- Cartridge versions unchanged: Kingsgate 0.1.0, Blackout Protocol 0.2.1, Coastal flight 0.4.0, Ironbreak 0.2.1, Blackline 0.3.2.

## Merge resolution

Nightfall art branched from `e79fdb8` and Blackout from `a4405f8`; `main` had since moved to 0.11.0. Conflicts were (a) version and cache strings — `main`'s newer values kept, then advanced to 0.12.0 — and (b) registries where Kingsgate and Blackout each added an entry — both entries kept (classroom cartridge list, game registry, Worker cartridge registry, validators, personal-run config, DEV menu, expansion cartridge lists, tests). The one code merge was `public/engine/game-host.js` (both tap handlers; map hidden for `noMap` or `hideMap`; Blackout's latched presses).

## Deployment order

The website and the session engine must change together: the website refuses to create sessions unless the server reports the same version. Do this between classes.

1. Merge the pull request for `implement/mathquest-v0.12.0` into `main`. Render publishes the website within a few minutes.
2. Immediately run `Deploy_Backend_Windows.bat` on the Windows computer (it tests, then updates the existing `mathquest-prototype` Worker; its allowed-origins list already includes the Render address).
3. Open `https://mcada-mathquest.onrender.com/api/health` and confirm `"version":"0.12.0"`.
4. Start a test session; play one Blackout Protocol gate, one Kingsgate gate and a Nightfall run to see the new art.
