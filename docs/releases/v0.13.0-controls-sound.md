# MathQuest v0.13.0 — shared D-pads and iPad sound (implementation checkpoint)

**Status:** Implementation checkpoint on `implement/v0.13.0-controls-sound`. Not merged or deployed. Spec: [v0.13.0](../change-specs/v0.13.0-controls-sound.md) (approved 2026-10-15). Frontend only: the Worker is unchanged (`engineVersion` stays 0.12.0), so no backend deployment is needed.

## Changes

- `public/engine/pad.js` (new, single owner): Mega Man **cross** and **8-direction** pad (U-17) on `held-input.js` (U-10); styles injected by the module, so Math Arcade needs no extra CSS.
- `controls.js`: profiles with `pad` render the pad; **Nightfall 1 and False Haven** use the cross (up = forward, down = reverse, left/right = turn; Run, Fire round; Search/Use, Change weapon small).
- **Journey** (classroom host and solo practice), **Coastal Escape** (`action-host.js`, `directional-input.js`), **Ironbreak** (classroom host and practice page): 8-direction pad; Ironbreak's round thumbstick removed.
- `public/engine/audio-unlock.js` (new, moved from Math Arcade): loaded first on the student page and every practice/DEV page.
- `game-audio.js`: Sound button no longer throws before audio has started. `games/journey/audio.js`: 3× master volume through a limiter (skipped when a host already boosts).
- Frontend version 0.13.0 (`BRAND.version`, page titles, module cache keys).

## Not changed (recorded under U-06)

- Historical generated files keep their old controls and version: `Ironbreak-v0.1.0-practice.html`, `Ironbreak-v0.1.0-cartridge-review.html`, `reviews/*` bundles, `aerial-practice-v0.x/`, `standalone/*`. The Ironbreak practice builder now includes `pad.js` and the audio unlock for the next generated version.
- Vault 7, Blackline (left/right only), Kingsgate, Blackout (tap) — unchanged by design.

## Math-escape audit (spec §4)

Gate questions, answers and attempts are held on the server; reload, back, close/reopen or rejoin returns the same question; every action run is issued once per student per stage with no restart command; Kingsgate has no question rounds in MathQuest and resumes the same run after a reload. The Math Arcade Kingsgate loophole does not exist here.

Two loopholes found, **not fixed in this checkpoint (owner decision needed)**, both because MathQuest has no teacher sign-in:
1. The setup page anyone reaches at the site root shows the "Developer tools" links to no-math practice/DEV pages.
2. Anyone can create a room (`POST /api/sessions` is unauthenticated) with three self-written questions and play any cartridge.
Minor: `/api/engine-preview` is unauthenticated and returns sample answers.
