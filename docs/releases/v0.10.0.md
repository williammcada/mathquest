# MathQuest v0.10.0 — release notes

**A WILLIAM MCADA PRODUCT** · 13 October 2026

Release of the verified Math Engine integration (candidate 0.10.0-rc.5, `292fad1`; verification in `docs/verification/math-engine-v0.10.0.md`; spec `docs/change-specs/v0.10.0-math-engine.md`). Includes everything in v0.9.8. This release step only changes version numbers and documentation; no features were added.

## What changed

- **All code-generated mathematics comes from the Math Engine** (0.34.0-rc.3, MATH-ENGINE `10127fc`): 312 K–7 skills, 1,441 course items from Intermediate 4 to Algebra 2 with lesson names, and 10 extras. Questions, answer checks and simplest-form feedback come from the engine. Math Arcade uses the same engine build.
- **The 25 old preset modules are retired.** Each now runs on mapped engine skills; rooms and setups that name an old module keep working.
- **Teacher setup:** a skill picker by level (MathQuest sets, Grades K–7, each course, extras) with search and Preview.
- **Difficulty:** a student's Foundation/Challenge setting uses the engine's reviewed easier/harder related skill when one exists.
- **Student answers:** new keypad keys where an answer needs them (R, :, ;, AM/PM, <, x …) and typed answers for words.
- **Fix:** Nightfall's First Response rescue now opens for every room from v0.9.4 on. It had been limited to an exact version list, so new rooms would have skipped it.
- Platform and session engine **0.10.0**. Rooms created on 0.9.2–0.9.8 remain supported.

## Deployment order

The website and the session engine must change together: the website refuses to create sessions unless the server reports the same version.

1. Merge MATH-ENGINE pull request #4 (no visible change; Math Arcade reads the engine from there).
2. Merge MathQuest pull request #8 into `main`. GitHub Pages publishes the website within a few minutes.
3. Immediately run `Deploy_Backend_Windows.bat` on the Windows computer (it tests, then updates the existing `mathquest-prototype` Cloudflare Worker).
4. Open `https://vault7mathquest.netlify.app/api/health` and confirm `"version":"0.10.0"`.

## Known limits

Physical iPhone/iPad checks and school-network tests are not yet run. Cloudflare-side Worker startup was measured only by `wrangler check startup` in CI (24 ms locally; 1.0 MB gzipped).
